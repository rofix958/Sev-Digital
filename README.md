## ✨ المميزات

- 🏪 **متجر كامل**: 20 منتجاً رقمياً في 7 تصنيفات
- 🔍 **بحث وفلترة** فورية + 4 طرق ترتيب
- 🛒 **سلة تسوق** محفوظة على الجهاز (LocalStorage)
- 💳 **دفع مبسّط** (تأكيد يدوي — بدون بوابات دفع متقدمة)
- 🎛️ **لوحة تحكم بصرية** لتعديل المنتجات والتصنيفات والإعدادات بدون كتابة كود
- 🎨 **ألوان قابلة للتخصيص بالكامل** من ملف إعدادات واحد
- 📱 **تطبيق جوال PWA**: تثبيت على الشاشة الرئيسية + اشتغال بدون إنترنت
- ⌨️ **RTL كامل** بخط Cairo العربي
- ⚡ حركات الظهور + شريط تطبيق سفلي للجوال

## 🛠️ لوحة التحكم

افتح **`admin.html`** (مثلاً `http://localhost:8080/admin.html`) و غادي تلقى:

| التبويب | شنو كيدير |
| --- | --- |
| **المنتجات** | إضافة / تعديل / حذف / نسخ / ترتيب + بحث وفلترة |
| **التصنيفات** | إضافة / تعديل / حذف التصنيفات |
| **الإعدادات** | اسم المتجر، العملة، الضريبة، العرض، التواصل، الألوان، منتجات الواجهة، آراء العملاء |
| **المعاينة** | كيفاش غادي يبان كلشي قبل ما تخرج |
| **التصدير** | توليد `js/data.js` و `js/config.js` جاهزين |

### طريقة الاستعمال

1. بدّل المنتجات ولا التصنيفات ولا الإعدادات.
2. سير ل **التصدير**.
3. حمّل `data.js` (و `config.js` إلا بدّلتي الإعدادات).
4. بدّل الملفات القديمة فـ مجلد `js/` ديال المشروع.
5. اعاود الرفع على GitHub باش يتحدّث الموقع.

> ⚠️ **مهم**: التعديلات كتبقى فـ `localStorage` ديال المتصفح فقط. الموقع الحي ما كيتبدّلش حتى تعوّض الملفات وتحدّث الموقع.
> و **ماشي عندها دخول** — أي واحد عندو الرابط يقدر يستعمل اللوحة، ولكن غادي يخدم غير فـ المتصفح ديالو هو.

### أخرى مفيدة

- **نسخة احتياطية JSON**: زر التنزيل فـ التصدير كيعطي نسخة ديال كلشي، وعندك زر الاسترجاع.
- **تراجع**: زر «تراجع كلشي» كيرجّع كلشي للمحتوى الأصلي ديال الملفات.
- **فحص قبل التصدير**: اللوحة كتأكد أن الملف المولّد صحيح (عدد المنتجات، المميزات، المعرّفات…) قبل ما تنسخو.
- **بلا صور ولا إيموجي للمنتجات**: المنتجات بلا `emoji` — التصنيفات وحدها عندها الأيقونات.

## ⚙️ التخصيص السريع

عدّل ملف **`js/config.js`** — كل شيء سيتغير تلقائياً:

```js
var SITE_CONFIG = {
  brandName: "Sev Digital",     // اسم المتجر
  brandShort: "SV",             // أحرف الشعار
  currency: "$",                // العملة
  colors: { red: "#8b5cf6", blue: "#ec4899", /* ... */ },  // هوية الألوان
  heroProducts: [20, 5, 14],    // منتجات الواجهة
  // ...
};
```

## 🚀 التشغيل محلياً

```bash
# أي خادم ثابت (Python مثالاً)
python -m http.server 8080
# ثم افتح: http://localhost:8080
```

أو فقط افتح `index.html` مباشرة في المتصفح للمعاينة.
> ميزة تثبيت التطبيق والاشتغال دون إنترنت تتطلب HTTP/HTTPS (وليس `file://`).

## ☁️ النشر على GitHub Pages

الريبو مجهّز بـ GitHub Actions — بعد رفع الكود على GitHub:

1. ارفع الملفات مستودعك (مع سكربت الاستضافة أو مباشرة من الويب).
2. اذهب إلى **Settings → Pages**.
3. من *Source* اختر `GitHub Actions`.
4. عند كل `push` إلى `main` سيُنشر الموقع تلقائياً.
